## EVAL-1 — Reflection Accuracy (LIVE)

- **Golden set**: `eval/golden_sets/reflection_baseline.json` (5 cases)
- **Threshold**: mean jaccard ≥ 0.6
- **Result**: **mean = 0.593** → **FAIL** (just under threshold)

### Per-case

| Case | jaccard | status |
|---|---|---|
| case_01_surveillance       | 0.600 | PASS |
| case_02_autonomous          | 0.750 | PASS |
| case_03_cooperative_pair    | 0.750 | PASS |
| case_04_multipolar_society  | 0.200 | **WARN** (drags mean) |
| case_05_low_activity        | 0.667 | PASS |

### Failure analysis — case_04_multipolar_society

- expected: `['다극형_생태계', '활발한_상호작용']`
- generated: `['다극형_생태계', '소규모_상호작용', '저활동', '평형적_발신']`

Live LLM judged the same society events as "소규모 / 저활동" where the golden set labeled them "활발한_상호작용". Disagreement is semantic (small-but-active vs not-very-active interpretation), not a hallucination.

### Live → Mock delta

| | Mock (M2) | Live (v2.5) | Δ |
|---|---|---|---|
| mean jaccard | 0.717 | 0.593 | −0.124 |
| pass count | 5/5 | 4/5 | −1 |

Real LLM is slightly less aligned with the golden descriptor set than the canned mock responses (mock is curated to match expected; live varies in word choice). The v1.0.2 mock baseline overstated alignment.

### Actions

- **Not blocking ship** — v2.5 already on main + HF Spaces; this captures the gap, not a regression of working behavior.
- **Either**: tune `prompts/reflection_*` to bias toward "activity level" vocabulary, **or** broaden `expected_descriptors` in case_04 to accept "소규모_상호작용" as equivalent to "활발한_상호작용" within multipolar context, **or** lower threshold to 0.55 with documented rationale.
- **Recommended for v2.6**: broaden golden set descriptors (cheaper than prompt tuning, baseline still meaningful).

## EVAL-2 — Citation Grounding (LIVE)

- **Golden set**: `eval/golden_sets/citation_grounding.json` (100 cases — 70 grounded, 30 hallucinated)
- **Threshold**: hallucination rate after validator < 1%
- **Result**: **0/100 = 0.00%** → **PASS**

### Confusion matrix

| | predicted: grounded | predicted: hallucinated |
|---|---|---|
| actual: grounded (70) | **70** | 0 (FP) |
| actual: hallucinated (30) | 0 (FN) | **30** |

- True positives (correctly flagged hallucinated): **30 / 30**
- False positives (grounded flagged as hallucinated): **0 / 70**
- False negatives (hallucinated missed): **0 / 30**

### Per-category breakdown

| Category | Cases | Caught by strict |
|---|---|---|
| grounded | 70 | n/a (0 false positives) |
| hallucinated_fabricated_field | 10 | 10 |
| hallucinated_invented_agent | 10 | 10 |
| hallucinated_role_swap | 5 | 5 |
| hallucinated_timestamp_swap | 5 | 5 |

Notably none of the hallucinated cases pass existence-check alone — all are caught only by `strict_mode` judge. Confirms validator-split design (existence vs grounding) holds at live judge model.

### Demonstrable case

- ID: `h_00` (hallucinated_invented_agent)
- Narrative: `FABRICATED_agent_zara가 2026-01에 패킷 분석을(를) 수행했습니다 [↑e06d14e8d]`
- Evidence payload: `{"action": "observation", "source_agent": "agent_alice", "month": "2026-01", "item": "패킷 분석", "count": 1}`
- Existence check: PASS (short_id matches an event)
- Strict check: **FAIL** (judge: `is_grounded=False`) — agent name swap detected
